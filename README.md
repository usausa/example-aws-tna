# example-aws-tna

AWS のサーバーレス構成と .NET で作る勤怠管理（Time & Attendance）システム。

## 基本方針

| 領域 | 方針 |
| --- | --- |
| 画面 | Blazor WebAssembly を S3 と CloudFront で配る |
| 認証 | 独自の JWT（RS256、秘密鍵は KMS）。リフレッシュトークンは HttpOnly の Cookie、アクセストークンはメモリに置く。API は CloudFront を通して画面と同じオリジンにする |
| API と処理 | HTTP API と Lambda（.NET、Native AOT）。始業と終業の打刻の集中にオンデマンドで備える |
| データ | DynamoDB |
| IaC | AWS CDK（C#） |
| 想定する顧客 | 中堅企業まで（1テナント〜3,000人）。オフィス、店舗・飲食・小売、工場・物流、医療・介護 |
| 労働時間制度 | 固定時間制、フレックスタイム制（清算期間1か月まで）、シフト制、1か月単位の変形労働時間制 |

## 主な利用者と作業

- 従業員: 毎日の出勤・退勤の打刻、必要に応じた休暇申請
- 承認者・管理者: 申請の承認、勤怠の確認・締め、マスタ設定
