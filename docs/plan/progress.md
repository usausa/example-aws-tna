- ⬜ F2-04 本人の画面（ホームの打刻とメモ、勤怠カレンダー、日別の詳細）

- ⬜ F2-05 打刻漏れの通知、メールの送信
- ⬜ F2-06 共有端末（登録、照合、打刻、初期 PIN の変更）と管理
- ⬜ F2-07 管理（ダッシュボード、勤怠の一覧、補正）
